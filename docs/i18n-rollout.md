# Optional English rollout — phase 1

Portuguese is the default. English is enabled only by explicit selection, and the choice is saved locally. Never infer language from browser settings or geolocation. The module makes no translation API requests and does not change XP, input values, URLs or user posts.

Phase 1: visible header selector; reviewed home navigation, headings, accessibility labels and controls; compatible footer PT/EN buttons; broken legacy language implementations removed. Unsupported legacy ES button is hidden until reviewed Spanish support exists. Existing PT/EN storage keys remain compatible.

This is NOT a complete translation of the app. Long-form articles, quiz questions, business descriptions, live news, messages generated by other scripts, internal pages and satellite apps require explicit translation catalogs and later tests. Unmapped content stays in Portuguese. No prices or partner conditions are altered. The module exposes ASF_I18N.coverage for diagnostics.

Future stages: full home catalog, internal pages, then ASF Manobras/Cutback and other satellites. Cross-subdomain preferences require an explicit reviewed mechanism; localStorage does not cross origins automatically.

Manual verification: clean browser with English system language must still open in Portuguese; choose English, reload, choose Português; confirm form values, existing XP and Cutback link are unchanged. Test menu, keyboard focus and mobile layout.
