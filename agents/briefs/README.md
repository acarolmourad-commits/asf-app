# Briefs do Agente de Métricas & Conteúdo

Índice dos briefs gerados pelo **ASF — Agente de Métricas & Conteúdo** (`agents/asf-metrics-content-agent.md`).

## Convenção
- Um arquivo por semana/cluster: `AAAA-Www-<cluster>.md` (ex.: `2026-W43-previsao-de-ondas.md`).
- Status de cada brief: `rascunho` → `aprovado` → `publicado (PR #___)`.
- Brief aprovado **não** é publicado automaticamente: a publicação é um PR separado, com aprovação humana.
