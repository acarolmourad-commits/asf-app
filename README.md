# 🏄‍♀️ ASF — Associação de Surf Feminino

Plataforma digital da ASF: comunidade, guias, treinos e previsão de ondas para mulheres surfistas no Brasil.

**Site:** https://acarolmourad-commits.github.io/asf-app/

## 📁 Estrutura

- `index.html` — página principal do app
- `app.js` — lógica principal (previsão Open-Meteo, comunidade, pontos, notificações)
- `aprender/`, `bem-estar/`, `praias/` — guias e conteúdo editorial
- `quiz/`, `mareas/`, `previsao-surf/`, `prancha-ideal/`, `surf-trip/`, `diario/` — ferramentas
- `assets/` — imagens, ícones e JS modular
- `docs/` — documentação, auditorias e planejamento
- `scripts/`, `.github/` — automação e workflows

## 🚀 Deploy

GitHub Pages (branch `main`). Alterações mergeadas na `main` são publicadas automaticamente.
